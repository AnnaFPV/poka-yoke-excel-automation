# Automação de Cálculos Laboratoriais com Poka-Yoke (Excel + VBA)

# Visão Geral

Este projeto foi desenvolvido com o objetivo de reduzir erros operacionais em cálculos laboratoriais realizados em planilhas Excel.

Em rotinas analíticas, é comum a utilização de planilhas com fórmulas que precisam ser replicadas manualmente. Esse processo pode levar à desconfiguração de células e, consequentemente, a erros nos resultados.

A solução proposta utiliza automação em VBA aliada ao conceito de *poka-yoke* (à prova de erro), garantindo maior confiabilidade e padronização.


# Problema

* Dependência de manipulação manual de fórmulas
* Risco de erro ao copiar ou alterar células
* Falta de padronização na execução dos cálculos
* Possibilidade de impacto na confiabilidade dos resultados


# Solução

Desenvolvimento de uma planilha automatizada em Excel com VBA, onde:

* O usuário insere apenas os dados de entrada
* Os cálculos são executados automaticamente por macros
* Os resultados são gerados de forma padronizada
* Os dados podem ser salvos automaticamente, reduzindo intervenção manual


# Funcionalidades

* Interface simplificada para entrada de dados
* Execução automática de cálculos via VBA
* Estrutura protegida contra alterações indevidas
* Redução da dependência de fórmulas visíveis ao usuário
* Padronização dos resultados gerados


# Conceitos Aplicados

* Poka-yoke (prevenção de erros)
* Automação de processos
* Padronização operacional
* Confiabilidade de dados


# Resultados Esperados

* Redução de falhas operacionais
* Aumento da confiabilidade dos cálculos
* Maior agilidade na execução das análises
* Padronização do processo


# Tecnologias Utilizadas

* Microsoft Excel
* VBA (Visual Basic for Applications)


# Aprendizados

Durante o desenvolvimento deste projeto, foram reforçados conceitos de:

* Estruturação lógica de processos

* Uso de ferramentas digitais para aumento de eficiência
